# SEKOLAH KITA

## Project Overview

Sekolah Kita adalah sistem informasi sekolah berbasis web menggunakan Laravel.

Project harus menyediakan website publik dan dashboard berdasarkan role pengguna.

## Technology

- Laravel 13
- PHP 8.5+
- MariaDB
- Redis
- Vite
- Ubuntu VPS untuk production

## User Roles

### Administrator

Mengelola seluruh sistem.

### Guru

Mengelola dan mengakses data yang berkaitan dengan guru.

### Siswa

Mengakses data yang berkaitan dengan siswa.

## Main Modules

- Public Website
- Authentication
- User Management
- School Profile
- Berita
- Prestasi
- Galeri
- Guru
- Siswa
- PPDB
- Contact
- Dashboard
- Notification
- Audit Log
- Cache
- Queue

## Development Principle

Project harus dibangun secara modular, secure, maintainable, responsive, dan production-ready.

Detail requirement setiap modul akan ditentukan sebelum implementasi.
